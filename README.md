# 🐾 Patinhas — Plataforma web de Adoção de Animais

Sistema web para gestão de adoção de cães e gatos, permitindo a visualização de pets disponíveis, submissão de pedidos de adoção e administração dos dados através de um painel administrativo.

> Projeto desenvolvido em prática full-stack.
---

## 🏷️ Tecnologias

- Angular  
- Node.js  
- Express  
- MongoDB  
- JWT  
- Cloudinary  

---

## 📌 Sobre o Projeto

O **Patinhas** é uma plataforma web dedicada à adoção responsável de cães e gatos.  
A aplicação permite que utilizadores consultem animais disponíveis, filtrem por características e submetam pedidos de adoção, enquanto administradores podem gerir pets, imagens e formulários através de um painel exclusivo.

O projeto foi desenvolvido com **backend em Node.js**, estruturado em **arquitetura MVC**, e **frontend em Angular**, garantindo uma aplicação moderna, organizada e segura.


---

## 🎯 Funcionalidades

### 👤 Utilizador
- Registo e login de utilizadores  
- Autenticação segura com JWT  
- Validação de formulários  
- Listagem de pets disponíveis  
- Filtros por espécie e cidade  
- Visualização de detalhes do pet  
- Submissão de pedidos de adoção  
- Visualização do perfil  
- Logout  

### 🛠️ Administrador
- Acesso ao painel administrativo  
- Gestão completa de pets (CRUD)  
- Upload de imagens   
- Download de formulários submetidos  
- Visualização de dados em tabelas

## 🚀 Instalação

### 🔹 Pré-requisitos
- Node.js (LTS)
- Angular CLI
- MongoDB (local ou Atlas)

---
### 🔹 Backend
cd backend
npm install
node server.js

### 🔹 Frontend
cd frontend
npm install
ng serve

A aplicação estará disponível em:
👉 http://localhost
